岘港按摩需要预约吗？

工作日下午通常可以直接去。海滩附近的晚上和周末较满：提前几小时通过WhatsApp或预约页面预约，并问清价格是否含小费。

按摩前该说什么？

在开始前和过程中说明哪里不舒服、想要多大力度。提出要求后技师会调整力度。

通常是：同样一小时，离海滩近的往往比市区贵。出发前比较公开的价目表；本指南标出了哪些店公布价格和时长。
